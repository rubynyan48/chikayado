りんかい線国際展示場駅から東京ビッグサイトまで

徒歩約7分

改札は1か所だけです。駅を出て右へ進み、ワシントンホテルの前を通ると会場の正面に出ます。

りんかい線はJR埼京線と直通する列車があり、新宿や渋谷、池袋、大崎から乗り換えなしで来られるのが強みです。ゆりかもめの駅より少し歩きますが、混雑が分散しやすいので大きなイベントの日に使う人も多い駅です。

  1. 改札を出て出口へ

    国際展示場駅の改札は1か所だけなので、迷うことはありません。改札を出たら案内に従って地上の出口へ向かいます。

    {{ photo("国際展示場駅の改札.jpg", "りんかい線国際展示場駅の改札") }}

  2. 駅を出たら右へ

    地上に出たら右に進みます。イベントの日は会場へ向かう人の流れができているので、その流れについていけば大丈夫です。

    {{ photo("国際展示場駅の出口.jpg", "国際展示場駅の出口を出たところ") }}

  3. コンビニの角を左へ

    しばらく歩くとローソンが見えてきます。ここを左に曲がると、正面の奥に東京ビッグサイトの会議棟が見えてきます。

    {{ photo("国際展示場駅から会場への道のローソン.jpg", "国際展示場駅から会場へ向かう道の目印のローソン") }}

  4. ワシントンホテルの前を通る

    そのまままっすぐ進み、左手に東京ベイ有明ワシントンホテルに入っているマクドナルドが見えたら、右斜め前へ進みます。

    {{ photo("東京ベイ有明ワシントンホテル前の道.jpg", "東京ベイ有明ワシントンホテルの前の道") }}

  5. 階段かエスカレーターで会場の正面へ

    東京ビッグサイトの正面に出たら、階段かエスカレーターで上がって会場に入ります。ここから先は、自分のイベントが開かれる展示棟へ館内の案内表示に従って進みます。

    {{ photo("東京ビッグサイトの正面.jpg", "東京ビッグサイトの正面") }}

ゆりかもめとどちらを使うか

りんかい線 国際展示場駅ゆりかもめ 東京ビッグサイト駅
会場まで徒歩約7分徒歩約3分
つながる駅大崎・大井町・新木場、埼京線直通で新宿・渋谷・池袋新橋・汐留・台場・豊洲
向いている人新宿や渋谷方面から来る人、ゆりかもめの混雑を避けたい人新橋や東京駅方面から来る人、少しでも歩く距離を減らしたい人

どちらの駅からでも会場には着けるので、泊まるホテルや来る方面に合わせて選べば問題ありません。帰りに片方の駅が混んでいたら、もう片方へ歩くという使い分けもできます。

道の途中にあるホテル

国際展示場駅から会場までの道沿いには、有明エリアのホテルが集まっています。いちばん近い東京ベイ有明ワシントンホテルは、まさにこの道順の途中にあります。前泊すれば、朝は駅を使わずにそのまま会場へ歩けます。
